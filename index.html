Performing Code

Live Coding in Performative Contemporary Practices

01 / Research

Code as an instrument of thought and action.

Performing Code explores live coding as a compositional, performative, and computational practice. It asks how algorithmic systems can shape musical expression, rhythmic organization, and the experience of performing with computational processes in real time.

The research develops through practical experiments, source-code studies, listening, and performance. Code is approached not only as a set of instructions for producing sound, but as material that can be revised, exposed, and negotiated during a performance.

Rather than aiming for predetermined outcomes, the work examines how rules, constraints, and relationships between processes can produce unexpected sonic behaviours and evolving structures.

The archive combines working code, short explanations, research notes, and documentation. It is intended to grow alongside the experiments rather than present a finished methodology.

01 — Pattern as a changing relation

SuperCollider / sketch

A simple pattern provides a stable starting point. Changing the sequence, duration, or relationship between pattern streams can shift the resulting rhythmic behaviour without changing the sound source.

SuperCollider 
(
Pbind(
    \instrument, \default,
    \degree, Pseq([0, 2, 5, 1, 4], inf),
    \dur, Pseq([0.25, 0.5, 0.25, 0.75], inf),
    \amp, 0.15
).play;
)

Research note: What happens to perceived pulse when the pitch sequence and duration sequence have different cycle lengths?

04 / Methods

From code to listening, and back.

Build

Develop small systems, operators, and patterns that can be inspected and recombined.

Listen

Evaluate their sonic and rhythmic behaviour through repeated listening and performance.

Modify

Adjust rules, parameters, and relationships in response to what the system produces.

Document

Publish code, observations, limitations, and useful references so each experiment remains traceable.

The method is iterative rather than linear. Listening can challenge the assumptions behind a system; code can then be revised to make room for different forms of interaction, instability, and control.

08 / About

Luis Sanz

Luis Sanz is a Zürich-based multidisciplinary artist, researcher, and musician working across computer music, experimental sonics, live coding, and audiovisual performance. His practice explores self-developed computational systems, autonomous sonic behaviours, rhythm, perception, and cultural memory.
